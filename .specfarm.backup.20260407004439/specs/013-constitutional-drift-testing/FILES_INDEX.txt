================================================================================
                         TYPICAL WORKFLOW
================================================================================

Step 1: Prepare
  1. Copy all files to another repo (use INSTALLATION.txt)
  2. Clone target repo and install SpecFarm
  3. Verify .specfarm/src/drift/drift_engine.sh exists

Step 2: Run
  1. Run: ./run_full_drift_experiment.sh ../target-repo
  2. Monitor progress (15 experiments, 5 per arm)
  3. Wait for completion (~30–90 minutes)

Step 3: Analyze
  1. Python auto-generates analysis-report.json
  2. Review success criteria (SC-001 through SC-004)
  3. Compare results

Step 4: Interpret
  1. Check if treatment reduces drift ≥20% (SC-001)
  2. Check if treatment accuracy ≥0.95 (SC-002)
  3. Check if difference is significant p<0.05 (SC-003)
  4. Check all runs completed (SC-004)
